**BG RandG** or **Back Ground Random Generator** is a generator of effects using SDL2, GLEW 2.1 and IMGUI. You can use it as a music visualizer, green screen, and more. 

- It has two types of render (cubes and triangles).
- 12 Types of Generators.
- And you can add custom backgrounds if you like, which are in the background folder; please respect the folders and resolutions I left in the README.
- It works on WinXP...Or at least it's supposed to.

### 🚀 Usage
- Open the program and start creating color combinations with these cubes, triangles, and backgrounds. :D
